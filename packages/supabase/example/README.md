# Supabase Dart web example

A bare-bones web app that queries, writes and listens to a `countries` table:

```sql
create table countries (
  id bigint generated by default as identity primary key,
  name text not null
);
```

It reaches the table through the typed table API, `client.table(Countries.table)`,
using the row, insert, update and column types in `web/supabase_schema.g.dart`.
That file is generated from the database schema with the
[Supabase CLI](https://supabase.com/docs/guides/cli/getting-started) and the
`supabase_typegen` dev dependency. Generate it again from your own project after
every schema change:

```sh
supabase gen types --lang dart --schema public --project-id YOUR_PROJECT_REF > web/supabase_schema.g.dart
```
